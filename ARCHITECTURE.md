# Architecture

Navigation: Today → Schedule → Clients → Extras → Account.

Visit rules implemented:
- Completed: Actual Service Date required; defaults to today.
- Not Completed: Actual Service Date + Observations required.
- Rescheduled: Observations required.
- Canceled: Observations required.
- Pending: no extra required fields.
- Future Actual Service Date blocked.
- Scheduled Date is read-only.

Database validation remains authoritative.
